🔑 Key Points
  • Access Port — พอร์ตที่ต่อกับ End Device (PC, IP Phone)
  • Trunk Port — พอร์ตที่ส่ง Traffic หลาย VLAN (Switch-to-Switch, Switch-to-Router)
  • 802.1Q — Tagging Protocol เพิ่ม 4-byte Header เพื่อระบุ VLAN
  • Native VLAN — VLAN ที่ไม่ถูก Tag ใน Trunk Port (default VLAN 1)
🌳 STP — Spanning Tree Protocol
STP ป้องกัน Switching Loop ใน Layer 2 Network โดยการ Block Port บางพอร์ตเพื่อสร้าง Loop-Free Topology
📋 STP Port States
  • Blocking — รับ BPDU เท่านั้น ไม่ Forward Frame
  • Listening — ส่ง/รับ BPDU เริ่มเลือก Root Bridge
  • Learning — เรียนรู้ MAC Address
  • Forwarding — Forward Frame ปกติ
  • Disabled — Port ถูกปิด
⚡ STP Variants
  • STP (802.1D) — Original, ช้า (30-50 sec)
  • RSTP (802.1w) — Rapid, เร็วขึ้น (1-2 sec)
  • MSTP (802.1s) — Multiple Instance STP
  • PVST+ — Cisco Per-VLAN STP
  • Rapid PVST+ — Cisco Rapid PVST

🗺️ Routing Protocols — OSPF, BGP, EIGRP
OSPF (Open Shortest Path First) — Link State Protocol ใช้ Dijkstra Algorithm คำนวณ Shortest Path ทุก Router มีแผนที่ Network เหมือนกัน (LSDB)
🔑 OSPF Key Concepts
  • Router ID — ตัวระบุ Router ใน OSPF (32-bit)
  • Area — กลุ่ม Router Area 0 คือ Backbone
  • DR/BDR — Designated Router ใน Broadcast Network
  • LSA — Link State Advertisement ข้อมูล Topology
  • LSDB — Link State Database แผนที่ Network
  • Metric = Cost — 100Mbps/Bandwidth (default)
  • AD = 110 — Administrative Distance
! กำหนด OSPF Router(config)# router ospf 1 Router(config-router)# router-id 1.1.1.1 Router(config-router)# network 192.168.1.0 0.0.0.255 area 0 Router(config-router)# network 10.0.0.0 0.255.255.255 area 1 ! Passive Interface (ไม่ส่ง Hello) Router(config-router)# passive-interface Gi0/0 ! ปรับ Cost Router(config-if)# ip ospf cost 10 ! ดู OSPF Neighbor Router# show ip ospf neighbor Router# show ip ospf database Router# show ip route ospf
BGP (Border Gateway Protocol) — Path Vector Protocol ใช้สำหรับ Inter-AS Routing (ระหว่าง ISP) BGP คือ Protocol ที่ทำให้ Internet ทำงานได้ เป็น Protocol ที่ซับซ้อนและทรงพลังที่สุด
🔑 BGP Key Concepts
  • AS (Autonomous System) — กลุ่มเครือข่ายที่มีนโยบาย Routing เดียวกัน
  • iBGP — BGP ภายใน AS เดียวกัน
  • eBGP — BGP ระหว่าง AS ต่างกัน
  • BGP Peer/Neighbor — ต้อง Configure แบบ Manual
  • AS-PATH — รายการ AS ที่ Route ผ่านมา
  • MED — Multi-Exit Discriminator เปรียบเทียบ Route ใน AS เดียวกัน
  • AD = 20 (eBGP) / 200 (iBGP)
! กำหนด BGP Router(config)# router bgp 65001 Router(config-router)# bgp router-id 1.1.1.1 ! กำหนด eBGP Neighbor Router(config-router)# neighbor 203.0.113.1 remote-as 65002 ! กำหนด iBGP Neighbor Router(config-router)# neighbor 10.0.0.2 remote-as 65001 ! Advertise Network Router(config-router)# network 203.0.113.0 mask 255.255.255.0 ! ดู BGP Table Router# show ip bgp Router# show ip bgp summary Router# show ip bgp neighbors
EIGRP (Enhanced Interior Gateway Routing Protocol) — Cisco Proprietary Hybrid Protocol ผสมระหว่าง Distance Vector และ Link State ใช้ DUAL Algorithm คำนวณ Loop-Free Path
🔑 EIGRP Key Concepts
  • DUAL — Diffusing Update Algorithm ป้องกัน Loop
  • Successor — Best Route ไปยัง Destination
  • Feasible Successor — Backup Route พร้อมใช้ทันที
  • FD / RD — Feasible/Reported Distance
  • Metric — Bandwidth + Delay (default)
  • AD = 90 (internal) / 170 (external)
  • Hello/Hold Timer — 5s/15s (LAN), 60s/180s (WAN)
! กำหนด EIGRP Router(config)# router eigrp 100 Router(config-router)# network 192.168.1.0 0.0.0.255 Router(config-router)# network 10.0.0.0 0.255.255.255 Router(config-router)# no auto-summary ! Named Mode (รองรับ IPv6) Router(config)# router eigrp MYEIGRP Router(config-router)# address-family ipv4 unicast autonomous-system 100 Router(config-router-af)# network 0.0.0.0 ! ดู EIGRP Router# show ip eigrp neighbors Router# show ip eigrp topology Router# show ip route eigrp

🌐 NAT — Network Address Translation
+

NAT แปลง Private IP เป็น Public IP เพื่อให้อุปกรณ์ภายในเครือข่ายสามารถเข้าถึง Internet ได้ — แก้ปัญหาการขาดแคลน IPv4 Address

1
PC ส่ง Packet ออก
Src: 192.168.1.10:5000 → Dst: 8.8.8.8:80
2
Router ทำ NAT Translation
แปลง 192.168.1.10:5000 → 203.0.113.1:12345 (Public IP)
3
Packet ออกไป Internet
Src: 203.0.113.1:12345 → Dst: 8.8.8.8:80
4
Response กลับมา
Router ค้นหา NAT Table → แปลงกลับ → ส่งให้ 192.168.1.10:5000
! Static NAT (1:1 mapping) Router(config)# ip nat inside source static 192.168.1.10 203.0.113.10 ! Dynamic PAT (Overload) — ใช้บ่อยที่สุด Router(config)# access-list 1 permit 192.168.1.0 0.0.0.255 Router(config)# ip nat inside source list 1 interface Gi0/0 overload Router(config)# int Gi0/1 ! LAN side Router(config-if)# ip nat inside Router(config)# int Gi0/0 ! WAN side Router(config-if)# ip nat outside
🚦 ACL — Access Control List
+

ACL คือชุดกฎควบคุม Traffic ที่อนุญาตหรือปฏิเสธ Packet ตาม Source/Destination IP, Port, Protocol

📌 หลักสำคัญ: ACL ถูก Process แบบ Top-Down — Match Rule แรกที่เจอจะถูก Execute ทันที และท้าย ACL จะมี Implicit Deny All เสมอ
ACL Types
  • Standard ACL (1-99) — กรองด้วย Source IP เท่านั้น วาง ใกล้ Destination
  • Extended ACL (100-199) — กรองด้วย Src/Dst IP + Port + Protocol วาง ใกล้ Source
  • Named ACL — ตั้งชื่อ แก้ไขได้ง่ายกว่า
! Standard ACL Router(config)# access-list 10 deny 192.168.1.0 0.0.0.255 Router(config)# access-list 10 permit any ! Extended ACL Router(config)# access-list 100 permit tcp 192.168.1.0 0.0.0.255 any eq 80 Router(config)# access-list 100 permit tcp 192.168.1.0 0.0.0.255 any eq 443 Router(config)# access-list 100 deny ip any any log ! Apply บน Interface Router(config-if)# ip access-group 100 in

🔍 DNS — Domain Name System
+
DNS คือ "สมุดโทรศัพท์" ของ Internet — แปลงชื่อ Domain เป็น IP Address เช่น google.com → 142.250.x.x
📋 DNS Record Types
  • A — Domain → IPv4 Address
  • AAAA — Domain → IPv6 Address
  • CNAME — Alias → Domain
  • MX — Mail Server Record
  • NS — Name Server Record
  • PTR — IP → Domain (Reverse)
  • TXT — Text Records (SPF, DKIM)
🔄 DNS Resolution Process
  • 1. ค้นหา Cache (Local / Browser)
  • 2. ถามผ่าน Recursive Resolver (ISP)
  • 3. ถาม Root Name Server (.)
  • 4. ถาม TLD Server (.com, .th)
  • 5. ถาม Authoritative Server
  • 6. รับ IP Address กลับมา
  • 7. Cache ผลลัพธ์ (TTL)
⚖️ QoS — Quality of Service
+
QoS จัดลำดับความสำคัญของ Network Traffic — ทำให้ VoIP/Video ไม่กระตุก แม้ Link จะ Congested
📊 Traffic Classification
  • Voice (EF) — VoIP, ต้องการ Low Latency <150ms
  • Video (AF4) — Video Conference, ต้องการ Consistent Bandwidth
  • Critical (AF3) — Business Apps, ERP, SAP
  • Best Effort (BE) — HTTP, Email, ทั่วไป
  • Scavenger — P2P, ความสำคัญต่ำสุด
🛠️ QoS Mechanisms
  • Classification — จัดกลุ่ม Traffic (DSCP, CoS)
  • Marking — ติด Label บน Packet
  • Queuing — CBWFQ, LLQ จัดลำดับ Queue
  • Policing — Drop Packet ที่เกิน Rate
  • Shaping — ชะลอ Packet ที่เกิน Rate
  • Compression — ลดขนาด Header

# Auto Backup Config — ทำงานบน Devices หลายตัว import datetime from netmiko import ConnectHandler devices = [ {'host': '192.168.1.1', 'name': 'Core-SW-01'}, {'host': '192.168.1.2', 'name': 'Core-SW-02'}, {'host': '192.168.1.3', 'name': 'Edge-Router'}, ] def backup_device(device_info): date = datetime.date.today().strftime("%Y%m%d") conn_params = { 'device_type': 'cisco_ios', 'host': device_info['host'], 'username': 'admin', 'password': 'secret', } with ConnectHandler(**conn_params) as conn: config = conn.send_command('show running-config') filename = f"backup/{device_info['name']}_{date}.txt" with open(filename, 'w') as f: f.write(config) print(f"✅ Backed up {device_info['name']}") for device in devices: backup_device(device)

📦 Packet Encapsulation Animation

ดูว่า Data ถูกห่อหุ้มเพิ่ม Header/Trailer ในแต่ละ OSI Layer อย่างไร ตั้งแต่ Application ลงไปถึง Physical

🔽 Encapsulation — Sender (Layer 7 → 1)
แต่ละ Layer เพิ่ม Header (และ Trailer ใน Layer 2) ห่อหุ้ม Data จาก Layer บน เรียกว่า Encapsulation — ฝั่ง Receiver ทำสิ่งตรงข้าม (De-encapsulation)
📛 PDU Names
  • L7-5 → Data
  • L4 TCP → Segment
  • L4 UDP → Datagram
  • L3 → Packet
  • L2 → Frame
  • L1 → Bits/Signal
🔑 Header ที่สำคัญ
  • TCP: Src/Dst Port, Seq/Ack, Flags, Window (20B)
  • IP: Src/Dst IP, TTL, Protocol (20B)
  • Ethernet: Src/Dst MAC, EtherType + FCS (18B)
  • Ethernet MTU = 1500 bytes payload

🌐 IPv6 — Complete Guide

128-bit Address Space รองรับ 340 undecillion addresses — ทุก Network Engineer ยุคนี้ต้องรู้

📐 IPv6 Address Format
IPv6 = 128 bits แบ่งเป็น 8 กลุ่ม กลุ่มละ 16 bits (4 hex) คั่นด้วย : — ย่อได้ด้วย :: แทน consecutive zeros
2001:0db8:85a3:0001
Network Prefix (64 bits) — ISP กำหนด
0000:0000:0000:0001
Interface ID (64 bits) — จาก MAC (EUI-64) หรือ Random
📋 IPv6 Address Types
  • Global Unicast 2000::/3 — เหมือน Public IPv4
  • Link-Local fe80::/10 — Auto-config ทุก Interface
  • Unique Local fc00::/7 — เหมือน Private RFC1918
  • Multicast ff00::/8 — แทน Broadcast
  • Loopback ::1/128 — เหมือน 127.0.0.1
✂️ Shortening Rules
  • ตัด Leading Zeros: 0db8 → db8
  • แทน 0000 ต่อกันด้วย :: ได้ครั้งเดียว
  • 2001:0db8:0000:0000::0001
  • → 2001:db8::1
